IMPORTANT
---------

The Fibonacci/QPM geometry has been optimized independently
of the absolute physical scale.

The absolute scale is obtained only after the dimensionless
dual phase-matching pair has been found.

The SHG length calculation uses approximate refractive indices
and a phenomenological modal-overlap factor.

It is NOT yet a fabrication-ready optical design.

The next physical refinement should replace these assumptions
with:

1. MgO:LiNbO3 Sellmeier equations
2. waveguide mode calculation
3. modal overlap integral
4. propagation loss
5. temperature-dependent phase matching
6. actual poling duty cycle
7. domain-wall placement errors
8. radiation effects
9. photorefractive effects
10. pump depletion if required
